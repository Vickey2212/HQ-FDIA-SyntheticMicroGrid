# HQ-FDIA-SyntheticMicroGrid

This repository contains the source code for the proposed **HQ-FDIA (Hybrid Quantum-Classical Learning for False Data Injection Attack Detection in Microgrid Systems)** framework, along with the datasets used in the study.

# Dataset

The complete FDIA-SyntheticMicroGrid dataset is hosted externally
because of its large file size.

## Dataset Download

[Download the FDIA-SyntheticMicroGrid dataset](YOUR_GOOGLE_DRIVE_LINK)

## Dataset Configurations

The dataset contains the following IEEE benchmark systems:

- IEEE-5 bus
- IEEE-9 bus
- IEEE-14 bus
- IEEE-30 bus

Each configuration contains approximately 500,000 samples.

## Dataset Contents

The dataset includes:

- Measurement data
- Feature-selected datasets
- Binary attack labels
- Multi-class attack labels
- Spatio-temporal measurements
